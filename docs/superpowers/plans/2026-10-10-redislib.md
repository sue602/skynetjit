# redislib (Redis 兼容 Bitmap/Geo/HLL/SortedSet Lua 库) 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Redis 8.10.0 的 Bitmap/Geo/HyperLogLog/SortedSet 算法内核移植为 4 个 skynet luaclib 模块，命令面、编码、返回语义与真 Redis 逐字节一致。

**Architecture:** Redis 源文件"只删命令层"式移植进 `redislib-src/kernel/`（配 `redislib_port.h` shim，robj 用 `{void *ptr;}` 最小结构占位，zmalloc 路由 skynet_malloc）；`facade/` 为每命令重写 Lua 参数解析并按 RESP 结构忠实映射返回值；`lua/` 薄封装提供大写别名与表形态入参归一化。构建走 `integration/redislib.mk`（模式照抄 netbull.mk），`--no-redislib` 整组关闭。

**Tech Stack:** C（MinGW-w64 gcc 16 / Ubuntu gcc 13）、LuaJIT 2.1（OpenResty fork，5.1 C API + 5.2 laux 扩展）、skynet、无新增外部依赖。

**Spec:** `docs/superpowers/specs/2026-10-10-redislib-design.md`（本计划逐条实现其 §1-§8）

## 公共约定：facade 对象模型（所有任务共用）

`rl_common.h` 定义（任务 1 一并产出，签名即合同）：

```c
typedef enum { RL_BITMAP, RL_HLL, RL_ZSET, RL_GEO } rl_kind;
typedef struct rl_object {
    rl_kind kind;
    sds str;        /* bitmap/hll: Redis string 值本体（hll 含 16 字节 HLL header） */
    zset *zs;       /* zset/geo 使用；geo 的 member 为原始 member，score=geohash bits */
    lua_State *L;
} rl_object;

rl_object *rl_check(lua_State *L, int idx, rl_kind kind); /* 参数校验+错误消息 */
void rl_free_ud(lua_State *L, void *p);                   /* __gc 入口 */
/* RESP 风格返回值 pusher */
void rl_pushnilreply(lua_State *L);      /* -> false */
void rl_pushok(lua_State *L);            /* -> "OK" */
void rl_pushint(lua_State *L, long long v);
void rl_pushbool(lua_State *L, int v);
```

geo 对象 = `RL_GEO`，内部直接用 `zset*`（与 Redis 一致：GEO 键就是 sorted set）。

facade 通用命令骨架（以 setbit 为完整范例，任务表中其余命令按此模式机械展开）：

```c
/* BITMAP:setbit(offset, value) -> old bit number|false(参数错走 lua_error) */
static int l_bitmap_setbit(lua_State *L) {
    rl_object *o = rl_check(L, 1, RL_BITMAP);
    lua_Integer off = luaL_checkinteger(L, 2);
    int bit = (int)luaL_checkinteger(L, 3);
    if (off < 0 || off > INT64_MAX/8) return luaL_error(L, "offset is out of range"); /* 文本同 Redis */
    if (bit != 0 && bit != 1) return luaL_error(L, "The bit argument must be 1 or 0.");
    /* 内核：直接抄 bitops.c setbitCommand 的位运算三行（去 client 化） */
    sds s = o->str; size_t byte = (size_t)off / 8; unsigned mask = 1 << (7 - (off & 7));
    s = sdsMakeRoomFor(s, byte + 1 - sdslen(s) > 0 ? byte + 1 - sdslen(s) : 0);
    sdslen(s) 已扩展处理见实现注记（sdsIncrLen）；
    int old = (s[byte] & mask) ? 1 : 0;
    s[byte] = (old) ? (s[byte] | mask) : (s[byte] & (~mask));
    rl_pushint(L, old); return 1;
}
```
（注：内核语义以 `$RSRC/bitops.c setbitCommand` 原文为准逐行对照，上面是形状示例；
每个 facade 命令实现时必须打开对应 Redis 命令函数原文抄其计算部分，
参数解析用 luaL_* 替换 getLongFromObject 等，错误文本原样保留。）
